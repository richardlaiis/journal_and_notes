## Path Existence Queries in a Graph I - LeetCode
### thoughts
因為給定的陣列是非遞減的，所以一旦我們發現到連續的元素的差超過 `maxDiff` (有點像是形成一個阻礙)，就會多出一個 connected component，每個區間 (被 barrier 隔開的) 都會形成一個 component。
### Code
```cpp
class Solution {
  public: vector < bool > pathExistenceQueries(int n, vector < int > & nums, int maxDiff, vector < vector < int >> & queries) {
    vector < int > group(n, 0); // group number for each element
    int gp = 0;
    for (int i = 1; i < n; i++) {
      if (nums[i] - nums[i - 1] > maxDiff) {
        gp++;
      }
      group[i] = gp;
    }

    vector < bool > ans;
    for (auto arr: queries) {
      if (group[arr[0]] == group[arr[1]]) ans.push_back(true);
      else ans.push_back(false);
    }

    return ans;
  }
};
```
