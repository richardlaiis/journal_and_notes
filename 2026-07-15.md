## llm
Here's a focused set of resources to get functional quickly in each area — prioritizing "learn by doing" over long theory.

### PyTorch

- **[PyTorch Official "60 Minute Blitz"](https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html)** — the fastest way to get comfortable with tensors, autograd, and building a simple network. Genuinely takes about an hour.
- **[PyTorch "Learn the Basics" series](https://pytorch.org/tutorials/beginner/basics/intro.html)** — a step-by-step walkthrough (tensors → datasets → models → training loop → saving models), each page short and runnable.
- **PyTorch docs tensor operations page** — bookmark this as your syntax cheat-sheet; you'll reference it constantly early on.

### NumPy

- **[NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html)** — official and concise; covers array creation, indexing, broadcasting, and basic operations.
- **[100 NumPy Exercises](https://github.com/rougier/numpy-100)** — a GitHub repo of progressively harder exercises with solutions. This is probably the single best way to _drill_ syntax since you learn by solving small problems rather than reading.

## Python OOP (classes, etc.)

- **[Real Python: OOP in Python 3](https://realpython.com/python3-object-oriented-programming/)** — clear, practical, covers classes, inheritance, `self`, dunder methods (`__init__`, `__repr__`, etc.) which show up constantly in PyTorch (`nn.Module` subclassing).
- **[Corey Schafer's OOP YouTube playlist](https://www.youtube.com/playlist?list=PL-osiE80TeTsqhIuOqKhwlXsIBIdSeYtc)** — if you prefer video, this is widely recommended for going from zero to comfortable with classes, inheritance, and special methods.

### A tip that ties all three together

Since you'll likely use these together (PyTorch models are built via classes, and PyTorch tensors mirror NumPy syntax closely), a good exercise once you've skimmed the basics is:

- Write a small `nn.Module` subclass from scratch (forces you to practice `class`, `__init__`, `super()`, and `forward()`)
- Convert a NumPy array pipeline into PyTorch tensors and back — this cements the syntax overlap/differences between the two (e.g. `.numpy()`, `torch.from_numpy()`, broadcasting rules being nearly identical).
