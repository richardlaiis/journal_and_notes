## LeetCode 1331. Rank Transform of an Array
這題不應該花這麼多時間思考ㄉ QQ
### Approach
Ordered map
### Complexity
Maybe $O(N\log{N})$.
### Code (C++)
```cpp
class Solution {
    public: vector < int > arrayRankTransform(vector < int > & arr) {
        map < int, int > mp;
        vector < int > arr1 = arr;
        sort(arr1.begin(), arr1.end());
        for (auto & x: arr1) mp[x] = 0;
        for (auto & x: arr1) mp[x]++;
        int curr = 1;
        for (auto & x: mp) x.second = curr++;

        int n = arr.size();
        for (int i = 0; i < n; i++) arr[i] = mp[arr[i]];
        return arr;
    }
};
```
